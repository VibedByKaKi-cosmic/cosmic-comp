# cosmic-comp APT repository

Binary packages for cosmic-comp built automatically from commits on `master`.

```sh
echo "deb [trusted=yes] https://raw.githubusercontent.com/VibedByKaKi-cosmic/cosmic-comp/refs/heads/apt stable main" | sudo tee /etc/apt/sources.list.d/cosmic-comp.list
sudo apt update
sudo apt install cosmic-comp
```
